# AI 选中发送

A browser extension for sending selected webpage text to AI assistants.

## Features

- Send selected text to ChatGPT, Gemini, Claude, DeepSeek
- Custom prompt templates
- Keyboard shortcuts
- Context menu support

## Permissions

- contextMenus: add right-click menu
- storage: save user settings
- scripting: interact with AI pages
- activeTab: access current tab

## Privacy

Selected text is only used for sending to user-configured AI services.
No data is collected.
